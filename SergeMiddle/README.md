The iPlug2 VST3 for the middle section, built from the contract in the repository root (`README.md`, `IPLUG2.md`, `BUILD.md`). The root Python files stay the reference; this folder ports them.

## Layout

| Path | Role |
| --- | --- |
| `SergeMiddle.cpp`, `SergeMiddle.h` | iPlug2 plugin: one Fold knob, stereo or mono, `ProcessBlock` |
| `config.h` | Plugin identity, I/O, latency, window size |
| `CMakeLists.txt` | iPlug2 CMake project, format VST3 |
| `dsp/WaveMiddle.h` | Header-only port of `wave_middle.py`: cells, Lambert W, `DRIVE_PEAKS`, smoother, FIRs, DC block, per-channel path |
| `dsp/WaveMiddleTables.h` | Generated by `tools/gen_tables.py` from `wave_middle.py` and the tap CSVs. Do not edit |
| `dsp/tests/` | Standalone C++ tests against the locked numbers. No iPlug2 needed |
| `resources/` | Plists, icons, Windows resources, font |

iPlug2 is the `iPlug2` submodule at the repository root.

## Choices made here

`BUILD.md` names the project and the window. This folder is that choice.

- Project name: `SergeMiddle`. Unique ID `'Smid'`, manufacturer ID `'Mrsy'`.
- Window: 300 × 300, one knob.
- Fold knob: 0.5 to 8, default 1, exponential taper so each octave of g gets the same travel.
- Reported latency: 16 samples. The two 63-tap filters delay 31 + 31 samples at the 4× rate, which is 15.5 audio samples.
- Formats: VST3. The macOS configure line is Unix Makefiles.

## Build the plugin

iPlug2 builds this plugin on macOS and Windows.

```text
git submodule update --init
cd iPlug2/Dependencies/IPlug && ./download-vst3-sdk.sh && cd ../../..
cmake -S SergeMiddle -B build/SergeMiddle -G "Unix Makefiles" -DCMAKE_BUILD_TYPE=Release
cmake --build build/SergeMiddle --target SergeMiddle-vst3
codesign --force --sign - build/SergeMiddle/out/SergeMiddle.vst3
```

On Windows, use `-G "Visual Studio 17 2022"` and run the download script from Git Bash. Skip the `codesign` line. The bundle is `build/SergeMiddle/out/SergeMiddle.vst3`. The `codesign` line is an ad-hoc signature so the Info.plist is bound.

The standalone APP compiles `resources/SergeMiddle-macOS-MainMenu.xib` with ibtool, so the format list is VST3.

## Test the DSP port (any platform)

```text
cmake -S SergeMiddle/dsp/tests -B build/dsp-tests -G "Unix Makefiles" -DCMAKE_BUILD_TYPE=Release
cmake --build build/dsp-tests
ctest --test-dir build/dsp-tests --output-on-failure
```

The tests read the root CSV files and `dsp/tests/chain_reference.csv`. They check:

- the embedded taps equal `halfband_taps.csv` and `upsample_taps.csv` bit for bit;
- `Process` matches `tests/transfer_g1.csv` within 1e-12 V, with exact odd symmetry;
- `audio_map` peaks at 1 for g in {0.5, 1, 1.2, 2, 3.3, 4, 8};
- the smoother coefficient and the 960-sample step;
- the decimator pass and stop probes, and the 1 kHz round trip inside the plugin path with the cells bypassed;
- a 20 Hz full-scale sine at g = 1 and at g = 2 peaks within 0.001 of 1 before the DC block;
- the 11.71875 Hz DC block figures, 1.152747 and 0.390095;
- the whole per-sample path (smoother, upsampler, cells, decimator, bound, DC block) against the Python reference within 1e-9.

## Regenerating

After a change to `wave_middle.py` or the tap CSVs:

```text
python3 tools/gen_tables.py
python3 tools/make_chain_fixture.py
```

`python3 tools/gen_tables.py --check` exits 1 when the header is stale.
